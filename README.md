# 文化祭 提供順ボード

スマートフォン・iPad向けの24席の提供順管理画面です。ビルドやインストールは不要です。

## GitHub Pagesで公開

1. このZIPを解凍します。
2. GitHubでリポジトリを作り、解凍したファイルをリポジトリの直下にアップロードしてコミットします。ZIPのままアップロードしないでください。
3. リポジトリの Settings → Pages から、ブランチによる公開（Deploy from a branch）を選びます。
4. ファイルを置いたブランチ（通常は main）と / (root) を選び、保存します。
5. 公開が完了したら、Pagesに表示されるURLをスマートフォンやiPadで開きます。

GitHub Pagesの利用可否はアカウントのプランとリポジトリの公開設定に依存します。
公式手順: https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 操作

- 空席をタップすると、受付順に1、2、3…と番号が付きます。
- 提供待ちの席を約0.55秒長押しすると、完了確認が開きます。
- 「提供完了・空席に戻す」で番号を消し、後続の順番を繰り上げます。
- 「まだ・戻る」では変更しません。
- キーボードでは席にフォーカスしてEnterで操作できます。

## 配置

- 上段: 横向きの机を左右に2つ × 3組（6席）
- 中段: 縦長の机を上下に2つ × 3組（6席）
- 下段: 2×2の机 × 3組（12席）
- 計24席を個別に受付できます。

## 現在の仕様

状態は開いている画面内だけで保持します。再読み込みや画面を閉じるとリセットされ、別の端末やタブとは同期しません。
元のSitesの本人限定アクセス設定はこのZIPに含まれません。閲覧可能な範囲はGitHub Pages側の設定に従います。

## ファイル

- index.html: 画面
- style.css: 配置とスマホ・iPad向け表示
- app.js: 受付・長押し・提供順の管理

ローカルでもindex.htmlをブラウザーで開いて動作を確認できます。
